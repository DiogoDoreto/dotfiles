lapdog — Host command review

Arbitrary host command authority. Not a sandbox.

All guest requests and reasons are untrusted. Guest-writable inputs and the live filesystem can change command behavior even after review. Only command text is frozen.

One command at a time, including root authentication. Timeout defaults to 2 minutes, maximum 30 minutes. Session ends after 4 hours. Output is always held initially.
